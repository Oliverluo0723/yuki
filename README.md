# Yuki

一件握在手裡看的雪。手機怎麼拿，就是你怎麼看雪。

起點是站在北海道的雪裡看雪落下：視線在「平視，看整片」和「低頭，看落在身上的那幾片」之間來回。這件作品把這兩種看法交給拿手機的姿勢。畫面上的雪都是 p5.js 畫的。

## 怎麼看

用手機打開，點一下開始（iPhone 會問能不能讀取「動作與方向」，要按允許）。

| 你做的事 | 看到的 |
|---|---|
| 直立拿著 | 平視：一層層排到遠處的雪，近的大而快，遠的小而慢 |
| 左右歪 | 雪永遠朝真正的地面落，所以會往低的那邊斜 |
| 慢慢放平到掌心 | 低頭：雪一片片落在玻璃上，停幾秒，化掉 |
| 手指碰玻璃 | 手指是暖的，碰到的雪立刻化；剛碰過的地方，新落的雪也化得快 |

在電腦上用滑鼠表達同一件事：往下捲是放平，左右移動是歪，游標就是手指。

## 兩個模式

點右下角那一行小字切換。

- **雪**（預設）：雪一直下，雪量、風、冷暖自己慢慢變化；晝夜照你這裡的時間。
- **北海道現在的天氣**：照北海道十個地點裡，現在雪下得最大的那一個，標籤會寫出地名、當地時間和氣溫。那邊沒下雪，畫面就沒有雪；讀不到天氣時也沒有雪。這個模式不會用模擬的雪代替。

地點清單在 `src/weather/places.ts`。想只看一個地方，把清單刪到剩一筆就好。

## 開發

需要 Node 24 和 pnpm。

```bash
pnpm install
pnpm dev        # https，給手機測
pnpm dev:http   # http://localhost:5174，只在這台電腦上看，沒有憑證警告
pnpm test       # 規則的測試（姿態、天氣換算、雪的運動、玻璃上的雪）
pnpm typecheck
pnpm lint
```

### 用手機測

手機要 https 才讀得到姿態，所以 `pnpm dev` 用自簽憑證開 https。

1. 手機和電腦連同一個 Wi-Fi。
2. 執行 `pnpm dev`，終端機會印出 `Network: https://192.168.x.x:5173/`。
3. 手機打開那個網址，憑證警告選「仍要前往」。

### 開發面板

網址加上 `?dev` 會出現面板，可以固定姿態、覆寫天氣、調整畫面。主控台裡也可以直接改 `yuki.overrides`、`yuki.tunables`。

要在裝置上用眼睛調的數值都在 `src/ui/devPanel.ts` 的 `tunables`：

| 名稱 | 作用 |
|---|---|
| `trail` | 每片雪拉出的短線多長。0 是點；超過 0.5 開始留下殘影，接近 1 像風的素描 |
| `uprightDeg` / `flatDeg` | 螢幕與水平面的夾角：多少度以上算平視、多少度以下算平放 |
| `dayGlass` | 白天時玻璃的亮度（玻璃永遠是深色的） |
| `budgetMax` | 雪片數量的上限（實際數量會依幀率自動增減） |

## 結構

```
src/
  input/     手機姿態、滑鼠、觸控 → 同一份姿態資料（posture、「下」的方向、暖區）
  weather/   北海道的天氣、常雪模式自己的變化 → 同一份雪的條件（SnowConditions）
  snow/      平視的雪片、落在玻璃上的雪、結晶；只讀上面兩份資料
  render/    p5 把雪畫出來；配色
  ui/        入口、右下角標籤、開發面板
  main.ts    串接
```

第一版沒有聲音。`snow/landing.ts` 的 `Landings.on()` 會發出落定、被手指融化、化掉三種事件，之後要加聲音訂閱它就好。

設計文件在 `docs/superpowers/specs/`，實作計畫在 `docs/superpowers/plans/`。

## 部署

靜態網站。推上 GitHub 之後，`.github/workflows/pages.yml` 會在每次推到 `main` 時建置並發佈到 GitHub Pages。第一次要到 repo 的 Settings → Pages，把來源選成 GitHub Actions。

實際模式的天氣來自 [Open-Meteo](https://open-meteo.com/)，資料以 CC BY 4.0 授權，入口畫面有標示來源。

- 免費 API 只供非商用：沒有訂閱、沒有廣告的個人網站算非商用。這個網站如果之後放廣告或收費，就要改用付費方案。
- 用量上限是每個 IP 每天 10,000 次、每小時 5,000 次、每分鐘 600 次。這件作品是觀眾的瀏覽器直接去問，每位觀眾在實際模式下每 15 分鐘問一次。
